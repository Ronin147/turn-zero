# Project Idea
This document will outline a project idea so that it can be used as reference for future development. 

## Project Name
*Suggest using standard names. Microsoft standard for .Net is {Company}.{ProjectName}.{Purpose} so KinsleyWorks.Sisyphus.Site as an example. Frontend projects are usually all lowercased*

## Purpose
*This should be a high level overview of what the project is and what it does. It should not go into too much detail, but should give a clear idea of what the project is about.*

## Features
*This should be a list of the main features of the project. It should be fairly comprehensive, at least as much as you can think of. Focus on unique or crucial features that will set the project apart from others.*

## Technology Stack
*Outline the desired technologies to be used in the project. This should include the programming languages, frameworks, libraries, and any other tools that will be used in the development of the project. Where will it be hosted? will it need email, text messaging, etc.?*

### Security Considerations
*This should include any security considerations that need to be taken into account when developing the project. This could include things like data encryption, user authentication, and secure coding practices. It is important to consider security from the beginning of the project to ensure that it is built with security in mind and to avoid potential vulnerabilities.*

### Development Tools
*This should include any tools that will be used for development, such as code editors, version control systems, and project management tools. This will help to ensure that the development process is organized and efficient.*

## Timeline
*This should be a rough timeline of the project, including major milestones and deadlines. This will help to keep the project on track and ensure that it is completed in a timely manner. Are you expecting to work on it a lot and get it done quickly or is it a side project and you don't have the time?*

## Audience
*Who is the project intended for? What are their needs and how will the project meet those needs? You can come up with Personas here to help guide your decision manking.*

## Personnel and Experience
*Who will be working on the project? What are their roles and responsibilities? What is their experience level and how will that impact the project? This is important to consider when planning the project and assigning tasks.*
